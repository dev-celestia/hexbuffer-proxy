🛡️ Install & Trust Root Certificate (hexbuffer-ca.pem)

To allow your browser, mobile device, or HTTP clients to intercept HTTPS traffic without TLS security warnings, install the downloaded root certificate authority:

1. Download Certificate:
⬇️ Download hexbuffer-ca.pem or curl -O http://127.0.0.1:8081/ca.pem
2. Trust on macOS:
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain hexbuffer-ca.pem
3. Trust on Linux (Ubuntu / Debian):
sudo cp hexbuffer-ca.pem /usr/local/share/ca-certificates/hexbuffer-ca.crt && sudo update-ca-certificates
4. Test with curl through Proxy:
curl --cacert hexbuffer-ca.pem -x http://127.0.0.1:8080 https://httpbin.org/get
